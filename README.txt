Windows 10/11, 64-bit. Requires a GPU/driver supporting Vulkan 1.3 and
dual-source blending. Connect a controller before starting.

Drag your Ace Combat 5 USA (SLUS_208.51) ISO onto PLAY.bat.
Alternatively, place it here as game.iso and double-click PLAY.bat.
An extracted disc folder named game also works. Game disc data is not included.
Extract the whole package to a writable folder before playing.
The initial black boot screen can last about 20 seconds.

Use the game's controls/settings. Keyboard: Enter = Start, arrows = D-pad,
X = Cross, S = Circle, Z = Square, A = Triangle; numpad 8/2/4/6 = left stick;
Q/E = L1/R1, 1/3 = L2/R2, right Shift = Select.

Saves are created in saves. Keep that folder when updating the build.
Close the game window to exit. For a bug, send last-play.log plus the mission,
what happened, and how to reproduce it. The log is replaced on each launch.
